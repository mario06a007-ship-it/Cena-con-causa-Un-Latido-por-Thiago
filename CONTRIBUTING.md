# Contribuir a Un Latido por Thiago

Gracias por estar interesado en contribuir a este proyecto benéfico.

## Cómo Reportar Problemas

Si encuentras un bug o tienes una sugerencia, por favor abre un issue en GitHub describiendo:
- Qué pasó
- Qué esperabas que pasara
- Pasos para reproducir
- Tu navegador y dispositivo

## Cómo Contribuir al Código

1. Fork el repositorio
2. Crea una rama para tu feature (`git checkout -b feature/AmazingFeature`)
3. Commit tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request

## Directrices de Desarrollo

- Mantén el código limpio y legible
- Usa comentarios en español
- Prueba en dispositivos móviles
- Respeta el diseño existente
- No hagas cambios en información sensible (datos bancarios)
